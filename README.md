# Tempo

Time tracking CLI for developers.

## Features

- Start/stop activity tracking
- Current session status
- Daily statistics
- PostgreSQL persistence
- Alembic migrations
- Docker development environment
- Automated tests

## Tech Stack

Python 3.13
Typer
SQLAlchemy
PostgreSQL
Alembic
Pydantic
Pytest
Docker
